# Results

Open the **Results** tab to see the leaderboard. There are five sub-tabs, each re-grouping the same scores.

## Sub-tabs

- **By Division** — one table per division, ranked by match percentage.
- **Overall** — all shooters in one table, divisions as a column.
- **By Stage** — one table per stage, with divisions nested under each.
- **By Category** — one section per category, then per-division tables.
- **By Tag** — one section per shooter tag, then per-division tables (handy for club vs. open squads).

![Results by division](/docs/screenshots/results-by-division.png)

**To do this in the app:** [Go to Results](app-tab:results)

## Shooter drill-down

Click any shooter's name in any results table to open their summary view: every stage with their raw score, penalties, hit factor, and match percentage.

## DQ table

Each results view has a **DQ table** at the bottom listing disqualified shooters and their DQ reason. The table has a red border to make it visually distinct.

![Results by stage with DQ table](/docs/screenshots/results-by-stage.png)

## Responsive layout

The results tables are responsive: full data table on desktop, card-based layout on mobile. The same data is shown — only the visual style changes.

**To do this in the app:** [Print results](app-action:print-results)
