# Overview

IPSCScore is a competition scoring app for practical shooting, IDPA, multi-gun, action steel, and other shooting sports.

This help guide explains how to use the app. Use the sidebar to jump to any section, click on screenshots to zoom, and click on the inline links to open the matching screen in the app.

## Quick tour

- **Matches** — Create and manage matches. Each match defines a competition with its own stages, shooters, and results.
- **Stages** — Stages (also called "situations" in some disciplines) are the individual scored exercises.
- **Scoring** — Enter scores per shooter per stage, on a desktop or mobile device.
- **Registration** — Manage the global shooter database and register shooters in a match.
- **Squadding** — Assign shooters to numbered squads and create shooter groups.
- **Disqualification** — DQ a shooter for the match (their scores become zero).
- **Results** — View results by division, overall, by stage, by category, and by tag.
- **Output** — Export results to CSV, PDF, or JSON; back up the database.
